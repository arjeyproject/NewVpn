# User Guide — راهنمای کاربر

## شروع
`/start` → منوی اصلی. زبان از منوی 🔵 زبان عوض می‌شود.

## ساخت VPN
1. 🟢 ساخت VPN → انتخاب پروتکل (VLESS پیشنهادی)
2. اسم پروفایل را بفرستید
3. تا ۶ کانفیگ **واقعاً تست‌شده** + لینک اشتراک دریافت می‌کنید
4. هر لینک تکی را کپی کنید یا QR بگیرید

## استفاده از اشتراک
لینک `…/sub/<token>` را در v2rayNG/Nekobox/Streisand به‌صورت Subscription اضافه کنید. منوی 🟢 اشتراک‌های من: کپی، QR، تازه‌سازی توکن (rotate)، لغو.

## تست اتصال
🔵 تست اتصال → پروفایل → وضعیت هر endpoint با latency و نوع تست. این تست endpoint است، نه تونل کامل.

## اکانت Cloudflare
🔵 اکانت Cloudflare → راهنمای توکن → ارسال توکن (پیام شما فوراً حذف می‌شود) → انتخاب دامنه.

## پشتیبانی
🔵 پشتیبانی → تیکت با دسته‌بندی (اتصال/Cloudflare/اشتراک/عمومی) — ادمین‌ها فوراً مطلع می‌شوند.
